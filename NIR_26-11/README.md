# NIR Forensics Data from 26 November 2026

## Overview
Near infrared imaging data of forensic samples. 30 samples per cloth are imaged at 6 positions at 4 rotations each.

## Folder Structure

```
NIR_26-11/
├── Calibration/    # Calibration images
├── RGB/            # RGB photo of each cloth
├── Rotation<X>/    # NIR image data for one rotation
│   ├── rot<N>_cloth<M>_<P>
│   ├── rot<N>_white_ref
│   └── ...
└── ...
```

## Calibration
Images taken during calibration of the imaging setup.

## RGB
One RGB photo of each cloth, all taken from the same perspective. These show where on the cloth each NIR image was taken (see [Image Position Order](#image-position-order)).

## Rotation Folders
Each `Rotation<X>` folder holds the NIR image data for one rotation. All files were generated by the imaging software and are fully lowercase.

### File Naming Pattern

```
rot<N>_cloth<M>_<P>
```

| Part | Meaning | Example |
|------|---------|---------|
| `rot<N>` | Rotation number | `rot1` |
| `cloth<M>` | Cloth number (`cloth1` = first cloth) | `cloth1` |
| `<P>` | Image position, 1 to 6 (6 images per cloth per rotation) | `1` |

Example: `rot1_cloth1_1` is rotation 1, first cloth, first of 6 images.

### Image Position Order

The position order is identical for every cloth and every rotation. Positions are relative to the cloth's RGB photo:

| Suffix | Position |
|--------|----------|
| `_1` | Top left |
| `_2` | Top right |
| `_3` | Middle left |
| `_4` | Middle right |
| `_5` | Bottom left |
| `_6` | Bottom right |

### Exceptions
- `Rotation4` has one extra file compared to the other rotation folders: `rot4_white_ref_end`.
